# PlasturgieProject

Ce projet Django permet de gérer la production, la qualité, les achats, les clients, les fournisseurs et les commandes dans une usine de plasturgie.  
Il offre une interface d’administration pour suivre les lots de production, les machines utilisées, les tests qualité, ainsi que la gestion des stocks et des ventes.

## Fonctionnalités principales

- Gestion des machines et des lots de production
- Suivi des tests qualité sur chaque lot
- Gestion des achats de matières premières
- Gestion des clients, fournisseurs et commandes
- Interface d’administration intuitive
